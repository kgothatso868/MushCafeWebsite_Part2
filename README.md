## Project overview
Mush Cafe is a local food business based in Randburg, South Africa. This project was developed as a multi-page static website to showcase the café’s warm branding, menu offerings, local business information, and customer enquiry process. The website is designed to be visually engaging, easy to navigate, and responsive across desktop, tablet, and mobile devices.

The project follows a practical web development workflow that covers planning, structure, styling, JavaScript interaction, and search engine optimisation. It is intended to serve as a professional digital presence for the business while also meeting the requirements of the PoE rubric.

## Website goals and objectives
- Promote Mush Cafe and its menu offerings to local customers.
- Improve online visibility and brand awareness in the Randburg area.
- Provide clear information about the restaurant, menu, location, and contact details.
- Simplify customer communication through enquiry and contact forms.
- Provide a user-friendly browsing experience with responsive navigation and mobile support.
- Showcase interactive JavaScript features such as menu filtering, search, sorting, lightbox gallery, and form validation.
- Apply SEO best practices including metadata, semantic markup, internal linking, and sitemap preparation.

## Target audience
- Local customers looking for affordable and satisfying meals.
- People searching for takeaway and grilled chicken meals near Randburg.
- Customers seeking convenience, quality, and local brand familiarity.

## Key features and functionality
- Responsive five-page static website
- Home, Menu, About, Contact, and Enquiry pages
- Professional warm café branding and consistent visual design
- Interactive menu search, category filtering, and price sorting
- Food gallery with clickable image lightbox
- Mobile navigation toggle for responsive layouts
- Contact form with validation and email preparation
- Enquiry form with relevant validation and confirmation feedback
- Embedded Google map for local business visibility
- Semantic HTML5 structure across all pages
- SEO metadata including title tags, meta descriptions, keywords, Open Graph tags, `robots.txt`, and `sitemap.xml`

## Part 2 details
### CSS styling and responsive design
The website uses a single shared stylesheet to maintain consistency across pages. The styling covers:
- typography and warm café palette
- responsive layout using flexbox and grid
- desktop, tablet, and mobile adjustments
- hover, focus, and active states for interactive elements
- button styling, cards, page heroes, forms, and footer layouts

### Responsive testing focus
- Desktop layout review
- Tablet layout review
- Mobile navigation and content stacking
- Consistent spacing and readability across screen sizes

## Setup and usage
1. Open the project folder in a code editor.
2. To preview locally, run: `python -m http.server 8000`
3. Open `http://localhost:8000` in a browser.
4. Navigate through the pages using the site navigation.
